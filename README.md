# Business Mileage Tracker 1.0.25

Trip History cards no longer repeat “Personal” beneath the Personal classification chip. Each card now shows the starting location and destination on separate one-line rows, with long addresses shortened using an ellipsis. The search field and sort control are reduced from 48 dp to 42 dp.

This release also includes the version 1.0.24 Reports fix that moves YTD logged miles beneath the YTD Performance title in larger type.

Install this APK over the existing app. Do not uninstall the app or clear its data if you want to preserve local trip history.
