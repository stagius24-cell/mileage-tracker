# Business Mileage Tracker 1.0.9

This update streamlines Trip History for mobile:

- Places search and sort controls in one row.
- Places drive type, business entity, and sync filters in one horizontal row.
- Groups date-sorted trips under compact date summaries.
- Reduces trip card height while keeping mileage, time, route, purpose, sync status, deduction, details, and delete access.
- Adds a one-tap search clear button.

Install over the existing app. Do not uninstall the app or clear its data before updating.
