# Business Mileage Tracker 1.0.15

This update normalizes the top spacing and title-row height on the Trip History and Reports screens. Both headers now use the same 16 dp top inset and 48 dp minimum row height, keeping their titles aligned when switching tabs.

It includes all changes from version 1.0.14, including the bicolor Settings switches and the automatic-drive stationary stop fallback.

Install this APK over the existing app. Do not uninstall the app or clear its data if you want to preserve local trip history.
