# Business Mileage Tracker v1.0.61

### Release Notes (v1.0.61):
- **Combined Create Report Action**:
  - Replaced the cluttered top buttons (CSV, PDF, and multiple filter pills) with a single, clean **Create report** button featuring the reports icon.
- **80% Opacity Blurred Floating Dialog**:
  - Clicking "Create report" opens a floating dialog with 80% opacity, a blurred background (`Modifier.blur(8.dp)`), and a dimmed backdrop.
  - The dialog offers customizable yearly report generation options:
    - **Tax Year**: Select from available tax years.
    - **Drive Type**: Filter by **Business**, **Personal**, or **All**.
    - **Format**: Select between **PDF** or **CSV** formats.
    - **Export Action**: Direct export/share launcher for the chosen configuration.
