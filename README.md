# Business Mileage Tracker 1.0.32

Edit and delete actions now appear at the lower-right of the More info tab. Route and More info use a sliding selected indicator, animated color changes, and a selected-icon scale animation that match the bottom navigation timing.

The green close button over the map now uses 70% opacity with a subtle blur.

Install this APK over the existing app. Do not uninstall the app or clear its data if you want to preserve local trip history.
