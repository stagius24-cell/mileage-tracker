# Business Mileage Tracker 1.0.20

- **Light Theme Contrast:** Increased screen background gray shade by ~10% (`#F8FAFC` -> `#E2E8F0` Slate-200, borders `#CBD5E1`), giving cards and tables crisp, non-subtle visual contrast.
- **Header Spacing Compacted:** Minimized excessive empty space above and within the Dashboard header (top padding, month picker row, filter chips, secondary metrics, and card gaps) so content sits higher up on the screen.
- **Tesla Drive Tracker:** Retains compact table with **LIVE MILES** centered, **DURATION** on left, **SPEED & Waypoints** on right.
