# Business Mileage Tracker 1.0.4

This APK updates the run-96/1.0.3 installation in place and preserves existing app data.

After installation:

1. Open **Settings**.
2. Under **Primary Vehicle**, enable **Stop Using Vehicle Bluetooth**.
3. Allow the Nearby devices permission if Android asks.
4. Tap **Choose Vehicle Bluetooth** and select the paired car.

When that car disconnects during an automatically detected drive, the existing four-minute safety timer starts. Reconnecting before it expires cancels the stop.

Do not uninstall the existing app or clear its data before updating.
