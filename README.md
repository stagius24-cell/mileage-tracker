# Business Mileage Tracker 1.0.23

Trip Details now uses a receipt-style layout: total miles, simple date, and potential deduction share one summary row; the route map is larger; and tabs switch between route endpoints and trip status. Start and destination rows each show their timestamp. Edit and delete actions sit at the right edge of the tab strip, and deletion requires confirmation.

This release preserves the newer dashboard changes already on `main`, including the compact tracking table and dashboard controls.

Install this APK over the existing app. Do not uninstall the app or clear its data if you want to preserve local trip history.
