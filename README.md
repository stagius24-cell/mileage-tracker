# Business Mileage Tracker 1.0.24

The Reports YTD card now places business miles directly beneath the YTD Performance title in larger, bold green type. This prevents the title and mileage from overlapping on narrow phones.

Install this APK over the existing app. Do not uninstall the app or clear its data if you want to preserve local trip history.
