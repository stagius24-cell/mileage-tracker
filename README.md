# Business Mileage Tracker 1.0.31

Trip Details now opens with the route map at the top. A green circular X button overlays the map in the upper-left corner. The date, mileage, and potential deduction moved into the Route tab above the starting location and destination.

The map display is simpler: on-map zoom buttons are hidden, the route and endpoint markers are slightly lighter, and the initial view limits excessive close zoom. Pinch, drag, the recorded route, and required OpenStreetMap attribution remain available.

Install this APK over the existing app. Do not uninstall the app or clear its data if you want to preserve local trip history.
