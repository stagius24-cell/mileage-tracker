# Business Mileage Tracker 1.0.17

Trip Details now uses a compact two-column summary. Total distance is larger on the left; classification, date, time range, sync status, and duration appear on the right. The duplicate time row was removed from the location card.

The extra inset above the Trip Details title was removed. Tax and classification information is now a collapsible section that stays closed by default while preserving business entity, purpose, IRS rate, estimated deduction, tracking method, and notes.

Install this APK over the existing app. Do not uninstall the app or clear its data if you want to preserve local trip history.
