# Business Mileage Tracker 1.0.14

This update makes Settings switches clearly distinguishable:

- On: green track with a white thumb.
- Off: neutral track with a contrasting slate thumb.
- Disabled: faded versions of the same states.
- Colors adapt to light, dark, and automatic themes.

This build includes the version 1.0.13 stationary auto-stop fallback.

Install over the existing app. Do not uninstall the app or clear its data before updating.
