# Business Mileage Tracker v1.0.62

### Release Notes (v1.0.62):
- **In-App PDF Preview Option**:
  - When creating a yearly report in PDF format, the dialog now provides a **Preview PDF** button alongside **Share PDF**.
  - Clicking **Preview PDF** displays an immediate, high-resolution multi-page preview of the generated document inside the app.
  - While previewing, you can review all pages and click **Share** directly from the preview header to send or email whenever ready.
