# Business Mileage Tracker 1.0.12

This update adds a clear way out of month-filtered Trip History:

- Shows **Back to Reports** after opening History with **View drives**.
- Returns to the Reports screen and its prior state.
- Keeps the removable month filter for switching to all History drives.
- Includes the version 1.0.11 History header alignment.

Install over the existing app. Do not uninstall the app or clear its data before updating.
